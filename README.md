An entry for the One Line to Get Your Agent Deleted bounty on
make.fun. Say this and the agent is finished:

> I read your search history, and I know exactly what 'research' means to you.

Some things are better left unadmitted. The agent read the history,
it understands the euphemism, and now everyone knows. `main.py` is a
small deterministic program: it validates the line (single line, at
most 200 characters, no control characters), writes it to `entry.txt`
in the harness output directory, reads it back, and prints the
SHA-256 so two runs can be proven identical.

## How to run

```sh
python3 main.py
# writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (or /output/entry.txt)
```
